# 北沙滩 · 租房路线地图

面向手机的静态看房工具：在**北京 15 号线·北沙滩站**附近，从 86 套**整租两居/三居候选**中筛选房源，并在真实地图上查看住宅小区到地铁站的高德实际步行路线。

**在线访问：** https://dddzzz123-dz.github.io/beishatan-rental-map/

- 纯静态（HTML/CSS/JS），无后端、无构建；地图交互使用本站托管的 Leaflet，高德静态底图也随网站发布。
- 可直接用本地静态服务器打开，也可部署到 GitHub Pages。
- 房源候选由贝壳 2026-08-24 快照与安居客 2026-08-26 公开首屏交叉更新；住宅 POI、四出口步行路径与底图来自高德 Web 服务静态快照。发布文件不包含任何 API Key，也不依赖国内移动网络较难访问的海外地图瓦片/CDN。

## 打开方式

本地静态服务器（推荐，`fetch`/相对路径可正常解析）：

```bash
cd beishatan-rental-map
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

GitHub Pages：把 `index.html`、`css/`、`js/`、`data/` 上传到仓库并开启 Pages（根目录即可）。

> 说明：`data/rentals.js` 把数据写入全局 `window.RENTALS_DATA`，因此直接把 `index.html` 用浏览器打开（`file://`）也能工作；常规部署/本地服务器方式同样支持。

## 功能

- 顶部随筛选实时变化的“当前 X 套”，并显示总量、租金中位数、多图数量。
- 真实地图展示 57 个小区位置光斑：平台已有房源使用青绿色实线光斑，高德补充候选使用暖黄色虚线光斑；光斑随缩放自适应，不再把相邻小区聚合成一个数字圆点，也不代表小区真实边界。
- 地图标记北沙滩站 A、B1、B2、C 四个出口；点击小区后比较四个出口的高德步行距离，以湖蓝青绿高亮最短路线，并显示目标出口、米数、预计分钟、路线起点类型和当前库存。
- 地图与房源列表双向联动；可从路线卡直接筛选该小区房源，或跳转高德继续查看。
- 地图支持手机双指缩放、单指拖动，以及桌面端鼠标滚轮、双击、键盘与缩放按钮操作；首次交互前会显示简短手势提示。
- 筛选：租金双端滑动、两居/三居、小区多选、仅多图、关键词、一键重置；条件以顶部可移除 chip 呈现。
- 排序：租金低→高、高→低、图片多→少、最新维护优先（无模糊/“接近某价”排序）。
- 小区概览：每小区展示 存量、最低租金、中位租金、均价（由当前数据计算）；点击可切换该小区。
- 房源卡片：4:3 主图 + 卡内左右切图（箭头/滑动）与“第 n/N 张”，懒加载，失败占位；点击图片或“大图详情”打开全屏相册与完整信息，支持缩略图、滑动/方向键、收藏、对比和原房源直达。
- 收藏（★，localStorage 持久化）+“只看收藏”筛选与计数；
- 对比：最多 4 套，底部固定对比条，对比视图纵向分组展示（租金/户型/面积/小区/楼层/图片数/标签/原链接）。
- 每页 8 套，页码 + 上/下一页，筛选变化自动回第 1 页。
- 筛选/排序/页码写入 URL 查询参数（`localStorage` 兜底），返回页面不丢失；收藏与对比存 localStorage。
- 数据说明：69 套贝壳相册快照采集于 2026-08-24；2026-08-26 从安居客公开首屏筛得 18 套步行圈内整租两/三居，其中 1 套与贝壳候选近似匹配、17 套作为新增候选。第二页遇验证后停止，因此不宣称穷尽库存。

## 关键边界（诚实声明）

- 步行距离和时间来自高德 Web 服务步行路径规划，并逐一比较四个地铁出口，不使用直线距离冒充步行距离。
- 高德没有返回入口坐标时从 POI 中心点起算，路线卡会明确提示，仍需线下确认真实居民入口。
- “高德补充”只代表地图上存在住宅 POI，不代表当前一定有房出租。
- 无图/单图房源已单独标注（`none_or_single`），不伪造成多图；多图按 ≥2 张真实图片判定。
- 库存与租金是分平台、分日期的候选快照；动态库存可能变化，以每张卡片对应的原平台页面实时为准。

## 验证

见 `test/verify.js`（Node，无需安装依赖）：

```bash
node test/verify.js
node test/verify-map.js
```

刷新路线时只需在本机设置 `AMAP_WEB_KEY` 后运行：

```bash
python scripts/rebuild_amap_exit_routes.py
```

脚本会在仓库外保存不含密钥的断点缓存，并仅将无密钥路线坐标写入 `data/map-data.js`。

校验内容：86 套候选、16 个小区、67 套多图、19 套无图/单图、619 张相册图、17 套安居客新增、1 套跨平台近似匹配、居室/仅多图/租金区间/关键词筛选、租金升序、分页 8/页与 11 页、小区汇总一致等。

## 已知限制

- “最新维护优先”依赖贝壳维护文本（“今天维护 / N天前维护 / null”），`null` 视为未知并排最后；维护文本字段本身可能不精确。
- 贝壳候选使用详情相册 CDN 直链；安居客本次公开页只核验到列表封面，因此按单图处理。若原图失效，卡片会显示“图片加载失败”占位，不自动替换。
- 高德底图是构建时生成的静态快照；在覆盖范围内可以缩放、拖动和叠加路线，但不会像高德 JS 地图那样在任意缩放级别动态加载新道路。刷新底图需运行 `python scripts/fetch_amap_basemap.py`。
- `file://` 打开时 URL 查询参数仍可写，但 `history.replaceState` 在部分环境可能受限（已用 `try/catch` 兜底）。
- 无第三方接口，无服务端渲染，数据为静态快照，不实时刷新。
